# component-conventions

Conventions for writing agent components such as skills, layered on top of the agent's built-in authoring workflow.

## Install

Add the [agent-harness](../..) marketplace, then install the plugin:

```sh
claude plugin install component-conventions@agent-harness
```

## Skills

| Skill | Description |
|---|---|
| `/component-conventions:skills` | Use when writing or reviewing an agent skill. Adds conventions on top of the agent's built-in skill-creation workflow. |
