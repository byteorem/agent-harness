# retro

Reflects on completed work so the agent and your setup improve over time.

## Install

Add the [agent-harness](../..) marketplace, then install the plugin:

```sh
claude plugin install retro@agent-harness
```

## Skills

| Skill | Description |
|---|---|
| `/retro:reflect` | Run a retrospective on a session and propose changes to the agent's setup so future sessions go better. |
